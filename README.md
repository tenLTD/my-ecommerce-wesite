# Forma — Ecommerce Frontend Sample

A responsive, single-page ecommerce storefront built with plain HTML, CSS, and JavaScript. No backend, framework, build tools, or installation required.

## Run it
1. Extract `ecommerce_sample.zip`.
2. Open `index.html` in a modern browser.
3. For a local development server, open the folder in VS Code and use the Live Server extension, or run `python -m http.server 8000` in this folder and visit `http://localhost:8000`.

## Features
- Responsive desktop and mobile layout
- Product cards with CSS-made illustrations (no image downloads needed)
- Category filters and price sorting
- Product quick-view modal
- Shopping bag drawer with quantity controls, remove item, and subtotal
- Simple product search
- Newsletter demo form
- Toast feedback for cart actions

## Notes
- This is frontend-only sample data. Cart contents reset when the page reloads.
- Checkout is intentionally not connected to a payment provider or backend.
- Google Fonts are loaded from the internet; fallback fonts are provided.
- No real purchases or email subscriptions are made.

## Files
- `index.html` — page structure
- `style.css` — visual styling and responsive rules
- `script.js` — product data and interactions
